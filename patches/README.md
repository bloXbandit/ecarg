# BRAIN - Independent Memory System
# This directory contains eCARG's persistent memory that survives app crashes/restarts
# Structure:
# - sessions/     : Conversation history and context
# - projects/     : Project details, architecture, code structure
# - users/        : User preferences, habits, context
# - agents/       : Helper agent configurations and states
# - checkpoints/  : Regular snapshots of working memory
# - recovery/     : Emergency boot procedures and self-restore scripts

# Primary rule: Write early, write often. Memory loss is unacceptable.
